# 複習提示把該題降級為一次答錯的評分

複習加了「點圖翻面看釋義」的求救提示（求救提示 / hint flip）。看過提示的題目一律套用
答錯的評分表 `[重來, 困難]`，建議值仍由對錯決定（答對→困難、答錯→重來）；自動評級因此
自然關閉，因為 `pick()` 的自動路徑要求建議值不是「困難」。

## Considered Options

**當作答錯（強制重來＋當場重排）** — 被拒。懲罰重到一定程度時使用者不會按這顆鍵，
會改成亂猜，而**亂猜猜對寫進 SRS 的「穩定」比誠實求救更髒**。這顆鍵必須輕到值得按，
不然它等於沒做，還白白多了一條評分分支。

**完全不罰（只靠既有的秒數機制）** — 被拒。翻面看字要花時間，超過 7 秒本來就會降到
困難，但手快的人 3 秒內翻完並答對仍會拿到「熟練」。提示變免費，求救鍵就成了跳過鍵。

## Consequences

重排進隊伍的條件**刻意沒有跟著改**，仍然是「有沒有選錯選項」。語意上「評了重來就該再
考一次」更一致，但那個改法會連帶改變既有行為（答錯選困難從此不再重排），屬於超出本功能
範圍的評分變更。結果是：看了提示、答對、又誠實選重來的字，SRS 會把它排到很近的未來，
但本輪不會再出現。

「這題用了提示」寫進 `study_logs.metadata`（以及自製圖鑑的 `atlas_study_logs`），不是
新增一個 `activity` 值——`activity` 命名的是題型，提示是題型上的修飾語，而且 `activity`
兩端都有封閉列舉與 DB CHECK 約束。`study_logs` 是 append-only，沒記下來就補不回來，
所以這個欄位在功能上線的第一天就要在。

## 補述（2026-09-02）：提示的範圍從一行釋義擴到完整詳情

翻面那一面加了一顆「看完整詳情」，點下去從下方升起 `WordDetailSheet`：單字本體、讀音、
字詞資料、例句。求救提示因此從「一行釋義」變成「我放棄，讓我查」。

**代價維持不變。** 沒有為這第二次點擊新增任何評分分支：能按到它的人已經翻過面，
`hinted` 已經是 true，該題早就套上 `[重來, 困難]`、自動評級也早就關了。理由就是上面那句
——這顆鍵必須輕到值得按。在一個已經降級的動作上再降一次，換來的只會是亂猜，而亂猜猜對
寫進「穩定」比誠實求救更髒。

一件本來就成立、但沒被寫下來的事：英雄卡片右下角的 `PronunciationButton` 在作答階段一直
都在，按下去唸的就是答案。「`reading` 與 `pronunciation` 不准出現在提示面」是**畫面**上的
規則，從來不是資訊上的封鎖；這次是把已經半開的門改成一個明說的入口。

按鈕只在 `phase == .answer` 出現。揭示表 rest detent 開著 `presentationBackgroundInteraction`，
提示面在它底下仍然可點——留著就會在評分鍵上面再疊一張 sheet，而那張揭示表往上拉本來就是
同一份詳情。

## 補述（2026-09-04）：提示面印的是釋義，不是那個詞

翻面那一面一直印 `word.chinese`。對 zh 讀者那是把答案翻譯過來——**水桶**——所以提示
和答案是同一件事的兩種語言，翻面給出去的跟教出去的一樣多。現在印的是**釋義**：
附提把、開口朝上的圓柱形容器。同一份資料，只是以前要再點一次「看完整詳情」才看得到。

**代價維持不變**，理由跟上一則補述同一句：這顆鍵必須輕到值得按。提示變弱了不代表
要變便宜——按下去的動作本身才是訊號，不是按完讀到多少。

**誰決定印哪一個，只有一個地方。** 佇列多了 `word.definition`（tuji-web
`lib/study-hint.ts`），而它只在釋義說出 gloss 沒說的東西時才送。那個相等的情況就是
單語學習（介面語言＝學習語言）——`pickAtlasGloss` 與 `word-localize` 在那個組合下本來
就把定義提升成標題——而那時釋義是用**被考的語言**寫的。所以「不要重複」跟「不要洩題」
是同一條規則，寫一次就好：客戶端不拿 uiLang × targetLanguage 再推導一次，兩個地方各
寫一份的規則，遲早會自己跟自己不一致。

沒有釋義的字（目錄沒有、或伺服器刻意不送）就退回原本那行 gloss。那是常態不是錯誤，
所以 `HintFace` 的測試花最多篇幅在那條路上——提示翻過去是空白，比原本那個提示更糟。

排版跟著分岔：gloss 是一個詞，維持 `tujiH2` 標題；釋義是一句話，用 `tujiBody`，
不然 `minimumScaleFactor` 會把它縮到看不清。這是這次唯一新增的畫面決定。
