# 商店頁以日文學習優先，日本區的日文關鍵字欄不挪用

Tuji 教兩種語言（`LearningDirection` 只有 `zh-en`、`zh-ja`），但繁體中文與英文的商店頁刻意
寫成日文優先：

- **對象**是在日居住者與留學生的生活面——便利商店、藥妝店、叫不出名字的日常用品。
- **標題**把兩種語言都講出來，日文在前（方向：`看圖學日文英文單字`）。**副標題與前三張截圖**
  只對在日生活者說話；英文學習留一張截圖、描述裡一句話。
- **日文與簡體中文的商店頁不跟著改。** 日文頁的對象仍是學英文的日本母語者。
- **商店頁文字的真來源是 `fastlane/metadata`**，不是 App Store Connect 的網頁後台。

**為什麼不是中性定位**：2026-10-12 時五個商店區合計 1 則評分。「背單字」「英文單字」
「vocabulary」是各區最擠的詞，零評分的 App 排不進去；而原本的標題「看圖學單字」沒有任何一個
字提到日文或日本，近期新增的系列（便利商店、藥妝店、酒類、衣物）卻全是在日生活的內容。排名
來自具體，內容也已經往這邊長了。

## Considered Options

**世界通用、「學多種語言」** — 被拒。App 只教兩種，說超過了（`RELEASE.md`：metadata 不宣稱
尚未完成的能力）；而且沒有人搜「多種語言」，那是 Duolingo 這一級在佔的詞。真的加了第三種語言
再改，標題隨版本就能換。

**只講日文，英文學習從標題拿掉** — 被拒。標題有 30 字，「日文」「英文」「單字」放得下，不必
用一群現有使用者去換另一群。

**主打遊客** — 被拒。遊客待一兩週，要的是翻譯與現成句子；間隔重複要幾週才有感，永久會員也
沒有理由買。拍照做卡看起來像翻譯工具，產出的卻是學習卡片。

**搶 JLPT 關鍵字** — 被拒。內容沒有 N1–N5 分級。用這個詞排上去，進來的人拿不到他要的東西，
換來的是差評。

**以簡體中文為主** — 被拒，雖然在日外國人裡中國籍最多。這是觸及管道的判斷：做得到的社群在
繁體中文與英文這一邊。簡中商店頁因此維持由繁中轉字的現狀（用語是台灣的，不是大陸的）。

**把日本區的日文關鍵字欄改填繁中與英文的詞** — 被拒。日本區只索引日文與英文（美國）兩個
在地化的關鍵字欄，所以這是讓「已換成日本帳號、用中文搜尋的人」搜得到的唯一辦法；代價是放棄
日本母語者在日本區的搜尋。決定保留給日本母語者。

## Consequences

**已換成日本帳號、用中文搜尋的在日居住者，搜尋打不到。** 繁中關鍵字只在台灣區與香港區生效
（準備去日本、或人在日本但還用原帳號的人）；日本區能打在日外國人的只剩英文（美國）那一欄。
這一段人只能靠商店外的管道帶進來，所以 `/download` 的來源標記不是可有可無——沒有它就量不出
哪個管道有用。

**截圖要用日文學習的資料重拍，而且第一張是免費功能。** 第一張放日本生活圖鑑，拍照做卡放
第二張：零評分時最需要的是「裝了之後跟說的一樣」的使用者，第一個被承諾的東西不該要先付費。

**在台灣區搜「英文單字」「背單字」的人比較不容易找到 Tuji。** 這是選定的代價。

**後台改字會被蓋掉。** 有人直接在 App Store Connect 網頁改了文字，下次 `metadata_upload`
會把它覆寫回 repo 的版本。文字只從 repo 改。
