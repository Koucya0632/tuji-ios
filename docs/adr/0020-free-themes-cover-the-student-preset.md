# 免費主題涵蓋整個留學生組合，但兩份清單分開維護

不知道學什麼的人，從 **主題組合**（留學生、打工度假、旅遊）挑一組。非會員能用的組合只有
留學生：免費主題從 `fruits`、`bedroom` 兩個擴大為這兩個再加上留學生的六個主題（campus、
identity-documents、bank、postal-services、station-commuting、convenience-store），新帳號的
預設學習主題也從入門三主題（kitchen、bathroom、living-room）改成留學生組合。

**為什麼給非會員一整個組合**：原本的兩個免費主題是「隨便給兩個」，彼此沒有關聯；留學生正是
ADR-0017 的對象，一個完整、說得出用途的起點比兩個零散主題更能讓人留下來。旁邊上鎖的打工
度假與旅遊，就是會員能多拿到什麼的說明。

**為什麼預設改成留學生**：入門三主題在 v2 下對非會員全部上鎖——新的非會員一進今天就是三個
學不到的主題，伺服器把它們過濾成空的，沒有新字可學。

## Considered Options

**免費主題只留留學生六個，拿掉 `fruits`、`bedroom`** — 被拒。v2 下複習也過 `canStudyCard`，
拿掉之後既有非會員已學的字會從複習消失，等於刪掉他們的進度。

**免費主題直接由留學生組合推導（「組合裡的主題就是免費的」）** — 被拒。組合是內容編排，
免費是定價；推導的話，為了內容把一個主題加進留學生，就會無聲無息地改了價格。兩份清單各自
寫死，由測試保證「留學生 ⊆ 免費主題」——有人改壞時是紅燈，不是悄悄連動。

**預設依會員身分分流（會員入門三主題、非會員留學生）** — 被拒。Setup 跑的時候新帳號的
權益通常還沒到，預設會隨競態而變。

## Consequences

**免費主題變成原本的約 4 倍。** 留學生六個主題合計約 138 個字。

**免費主題收回會毀掉進度。** 以後若要縮小免費範圍，被移出的主題裡非會員已學的字會從複習
消失；縮小前要先決定那些字怎麼處理。

**改留學生組合要同時看免費清單。** 加一個非免費主題進留學生，測試會紅；要嘛一起放進免費
清單（定價決定），要嘛不加。非會員看到的留學生按鈕是否上鎖，只由「任一主題上鎖就整組上鎖」
決定，沒有特例。
